---
name: obsolete-behavior-references-removed
subject: Tests, comments, and documentation affected by a behavior change or removal
requirement: Remove tests, comments, and documentation that no longer apply when
  behavior changes or is removed. Test and describe the current behavior
  directly. Do not replace obsolete references with assertions or explanations
  that the old behavior is absent, unless that absence is an explicit
  requirement.
purpose: Keep tests and documentation aligned with current behavior without
  retaining obsolete implementation history.
---
